Assumptions made where the prompt did not settle the point:
 1. Doses are taken from aligned_5min.csv at interval level (bolus_u, est_basal_u,
    carbs_g), not from the raw bolus timestamps: a bolus is aged from the start of the
    5-minute interval that holds it (full dose in that row), and basal delivery in an
    interval is seen from the next row at mid-interval age, matching est_basal_iob_u.
 2. insulin_activity_u_per_5min = activity(t) x 5 min summed over bolus AND basal doses;
    carbs_absorbed_g_per_5min = C x 5/180 for every carb entry younger than 3 h.
 3. Folds: 14-calendar-day blocks starting 45 days after the first usable row
    ([date] -> first block [date]). The 3-day tail of window 1 ([date])
    and the 5-day tail of the train split ([date]) each hold under 7 days of data and
    are folded into the block before them; the [date] gap holds no rows and is skipped.
 4. Inside each training fold the last 20 % of rows (time order) is the validation
    fold; it drives early stopping (patience 100, as train_hypo_classifier.py) and
    fits the isotonic calibrator; the model is fitted on the first 80 %. The test
    block never influences its own model.
 5. Episode logic is the one in train_hypo_classifier.py (cv_ablation_exercise.py has
    none): a low episode is a run of readings < 4 with gaps <= 15 min merged; caught if
    any warning fired in the 30 min before it or during it; an alert episode is a
    maximal run of warned intervals. Days = distinct calendar days with scored rows.
 6. "Interval precision" = share of warned intervals (p >= 0.60) whose target is 1.
 7. Regimes: post-meal = min_since_carbs <= 180; post-exercise = hrs_since_exercise
    <= 4 (workout END); 2-5 h window = 120 <= min_since_carbs <= 300, where carbs are
    the carbs_g entries (every carb entry sits on a bolus row).
 8. Block bootstrap: resample the test blocks with replacement (same draws for every
    comparison), Brier difference = pooled difference over the resampled rows; 2,000
    draws, seed 20260923, percentile interval.
 9. Window 0 ([date] - [date]) is training-only in the first fold and is scored from
    [date] onward like everything else; nothing crosses the window-0 fence because
    the v2 features are computed per window and `clean` already excludes rows whose
    past hour spans the fence.
